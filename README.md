# Stargate address fonts

Fonts for displaying and typing Stargate address glyphs, created from three original fan fonts.

## Files
| Name | Description |
| ---- | ----------- |
| `StargateGlyphs.ttf` | Glyphs mapped into the Unicode plane-16 private use area |
| `Stargate*GlyphsASCII.ttf` | Three optional fonts for typing, one per gate, with glyphs on `A`-`Z` and `a`-`z` |
| `stargate-glyphs.html` | Click-to-copy cheat sheet with embedded font |
| `map.png` | Every glyph with its codepoint |

## Usage

* Standalone:
  * Install `StargateGlyphs.ttf`, open `stargate-glyphs.html`, click the glyphs you want, press copy and paste into your document.
* For typing:
  * Install one of the `Stargate*GlyphsASCII.ttf` files, type `A`-`Z` and `a`-`z` and apply that font.

## AI usage disclosure

The fonts and the html sheet were produced with the help of a large language model. The glyphs themselves are original authors' work.
